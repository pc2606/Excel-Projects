# Amazon Sales Data Analysis – Excel

## Project Overview

This project focuses on analyzing Amazon sales data using Microsoft Excel. The project demonstrates data analysis, data cleaning, and visualization techniques to extract meaningful insights from sales data.

## Dataset

The dataset contains Amazon sales-related information used for analysis and reporting.

## Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Excel Formulas
- Pivot Tables
- Data Visualization
- Dashboard Creation

## Project Objectives

- Analyze sales data using Excel
- Clean and organize the dataset
- Create meaningful summaries using Pivot Tables
- Identify useful sales insights
- Present the analysis through visualizations and dashboards
